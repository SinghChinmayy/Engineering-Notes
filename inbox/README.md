# Inbox

Drop raw study material here, then ask your agent to "process my notes":

- Markdown or text notes (`.md`, `.txt`)
- Photos of notebook pages (`.jpg`, `.png`, `.heic`, `.webp`)
- Scanned pages (`.pdf`)

Everything in this folder except this README is git-ignored, so your notebook is never published. After processing, inputs move to `inbox/processed/<date>/` until you have reviewed the result; delete them whenever you like. What went where is recorded in [`log.md`](../log.md).
