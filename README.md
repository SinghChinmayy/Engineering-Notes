# SQL Learning Journey

A public, hands-on record of how I am building practical SQL skills. This repository pairs concise concept notes with solved interview-style problems, making the learning process easy to review and the reasoning behind each query visible.

## Why this repository exists

I created this repository to learn SQL deliberately rather than collecting isolated answers. Each entry turns a concept or exercise into a reusable reference: the problem, a readable solution, and the key idea it reinforces.

For recruiters and collaborators, it offers a transparent view of my approach to problem solving: I break queries into clear steps, use appropriate SQL patterns, and document the reasoning so that the work can be understood and revisited.

## What you will find

- [Learning notes](notes.md) — self-contained explanations of SQL concepts, examples, and common pitfalls.
- [Practice questions](questions/) — interview-style exercises with their solutions and a short explanation of what each one demonstrates.
