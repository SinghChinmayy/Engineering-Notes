# SQL Learning

A public collection of SQL learning notes and practice questions. It is a place to document concepts, work through queries, and share useful examples for anyone learning SQL.

## Repository layout

- [`notes/`](notes.md) — explanations, references, and learning notes.
- [`questions/`](questions/) — practice questions and their solutions or working notes.
